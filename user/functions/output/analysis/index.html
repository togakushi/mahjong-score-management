分析コマンド¶

ポイント以外の情報を用いての成績分析、他プレイヤー/チームとの成績比較を行う。

コマンド構文¶

チャンネル内呼び出し:

<分析コマンド> [ターゲット] [オプション]

Note

分析コマンド は以下で定義される

  • analysis セクション の commandword

スラッシュコマンド:

/commandname analysis [ターゲット] [オプション]

Note

/commandname は以下で定義される

  • slackセクション の slash_command

  • discordセクション の slash_command

オプション概要¶

グラフ¶

グラフ表記に切り替える。

レポート¶

成績詳細レポートを生成する。

レート, レーティング¶

レーティングを集計。

対戦, 対戦結果¶

対局対戦マトリクス の表示。

統計¶

各プレイヤー/チームの成績比較。

素点¶

ゲーム終了時点の素点情報を基にした成績の分析を行う。
