ヘルプ出力¶

チャンネル内キーワードで呼び出せる機能のヘルプ

出力サンプル¶
$ uv run app.py --moderate -c /dev/null -s std --text="麻雀ヘルプ"
[yyyy-mm-dd hh:mm:ss,sss][WARNING][rule:info] remarks_words: empty
【機能呼び出し】
使い方：<呼び出しワード> [検索範囲] [対象メンバー] [オプション]
集計対象ルール識別子：default_rule

成績サマリ：
        呼び出しワード：麻雀成績
        検索範囲デフォルト：当日

成績グラフ：
        呼び出しワード：麻雀グラフ
        検索範囲デフォルト：当日

ランキング：
        呼び出しワード：麻雀ランキング
        検索範囲デフォルト：当日
        規定打数デフォルト：全体ゲーム数 × 0.05 ＋ 1
        出力制限デフォルト：上位 3 名

レポート：
        呼び出しワード：麻雀レポート
        検索範囲デフォルト：当日

メンバー一覧：
        呼び出しワード：メンバー一覧

チーム一覧：
        呼び出しワード：チーム一覧

【検索範囲に指定できるワード】
今日：20xx/mm/dd ～ 20xx/mm/dd
... 一部省略 ...
今年：20xx/01/01 ～ 20xx/12/31
去年：20yy/01/01 ～ 20yy/12/31
昨年：20yy/01/01 ～ 20yy/12/31
一昨年：20zz/01/01 ～ 20zz/12/31
最初：1900/01/01
最後：20xx/mm/12
全部：1900/01/01 ～ 20xx/mm/dd

【メモ機能】
使い方：<メモ記録ワード> <対象メンバー> <内容>
メモ記録ワード：

個別カウントワード：未登録ワードのすべてを個別にカウント

【ルールセット情報】
ルール識別子         default_rule
集計モード           四人打ち
素点                 25000点持ち / 30000点返し
順位点               30pt / 10pt / ▲10pt / ▲30pt
同点時               席順
成績記録キーワード   終局
記録数               0 ゲーム

【チャンネル設定情報】
チャンネル識別子：standard_io
デフォルトルール識別子：default_rule
チャンネル個別設定：---
セパレート機能：無効
