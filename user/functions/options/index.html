オプション処理ロジック

入力されたコマンド文字列はコマンド部分とオプション部分に分割され、オプション部分を以下のロジックで評価する。

  1. オプションの分類と抽出

    • 日付指定オプション の抽出

    • その他の定義済みオプションの抽出

    • オプションとして認識できないワードの抽出

  2. 検索範囲の確定

    • 抽出した 日付指定オプション を日付に変換

    • すべての日付の中から最小値と最大値を取得

  3. オプションの評価

    • 出現順に評価していく

    • フラグの変更、値の設定は上書きされる

  4. オプションとして認識されなかったワードの処理

    • チーム名と一致するかチェック

      • チーム名と一致し、かつ、 チーム オプションが指定されていない（個人集計が対象）場合、チームメンバーに展開し処理を続ける

      • チーム オプションが指定され低場合は ターゲット の対象に登録

    • 個人集計を対象としている場合、 レギュラーメンバー と一致するかチェック

      • 別名で指定されている場合、表示名に変換する

    • 結果を ターゲット の対象として登録

      • ゲスト無効 が指定されている場合、出力される ゲストメンバー の名前に guest_mark が追加される
