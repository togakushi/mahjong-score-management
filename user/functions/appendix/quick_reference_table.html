オプション組み合わせ早見表¶

オプションの組み合わせで出力される内容

凡例
空欄 … 未指定
✔ … 指定
⭕ … 追加指定
❌ … 指定禁止（指定する動作が変化する）
共通オプション
チーム … プレイヤー名/チーム名が未指定のときに集計対象をチームとする
規定数 … 指定ゲーム数に満たないプレイヤー/チームを非表示にする
