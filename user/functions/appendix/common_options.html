オプションに指定できる共通キーワード¶

Tip

複数のオプションが同時に指定されている場合は出現順序で処理され、結果を上書きしていく。

検索範囲指定オプション¶

集計の範囲や集計ゲーム数を調整するオプション。

日付指定オプション¶

指定されたキーワードを基にリストに追加する。

  • キーワードは複数指定可能

  • 実行時の時間を基準に算出

  • リスト内の最小値と最大値の期間を取る

キーワード

追加される日付

備考
当日¶

time_adjust を考慮した時間の日付
今日¶

今日の日付
昨日¶

昨日の日付
先週¶
先週の月曜日
先週の日曜日

実行日から7日前の週の月曜日～日曜日
今週¶
今週の月曜日
今週の日曜日
実行日が含まれる週
実行日が月曜日であればその週の日曜日まで
今月¶
今月月初の日付
今月月末の日付
先月¶
先月月初の日付
先月月末の日付
先々月¶
先々月月初の日付
先々月月末の日付
今年¶
今年の1月1日
今年の12月31日
去年, 昨年¶
前年の1月1日
前年の12月31日
一昨年¶
前々年の1月1日
前々年の12月31日
最初¶

記録されている最初のレコードの前日

集計対象のルール識別子で異なる日付が返る
最後¶

翌日の日付
全部¶
記録されている最初のレコードの前日
翌日の日付

最初から最後まで
YYYYMMDD¶

指定日 （連続した数字8桁）

MMとDDは常に2桁で指定する
YYYY-MM-DD, YYYY/MM/DD¶

指定日

MMとDDは常に2桁で指定する

回数指定オプション¶

キーワード

内容

備考
直近<NNN>¶

<NNN>回前からのゲームを集計

数字で指定
規定打数<NNN>, 規定数<NNN>¶

プレイ数が<NNN>回以下のメンバーを非表示にする

数字で指定

コメント検索オプション¶

ゲームコメントが付いているものを集計対象にする。
指定したコメントが付いていないゲームは集計対象外となる。

キーワード

内容

備考
コメント<XXX>¶

ゲームコメントを<XXX>で検索する

部分一致
集約<NNN>¶

ゲームコメントの文字列を先頭から<NNN>文字目でグループ化する

集計対象ルール指定オプション¶

キーワード

内容

備考
横断, mix, mixed¶

未マッピングの ルールセット も集計対象に含める

自動的に 規定打数0 が付与される
サンマ, 三麻, 三人打, 三人打ち¶

mode=3 が指定されている ルールセット をすべて含める

マッピングされている ルールセット のみ
ヨンマ, 四麻, 四人打, 四人打ち¶

mode=4 が指定されている ルールセット をすべて含める

マッピングされている ルールセット のみ

See also

  • keyword_mappingセクション

  • ルールセット定義

集計結果をファイルで出力する。

キーワード

テキスト形式でファイル出力

UTF-8

CSV形式でファイル出力

UTF-8

ゲスト関連オプション¶

ゲストプレイヤー の扱いを変更するオプション。

キーワード

内容

備考
ゲストあり¶

集計結果にゲストの成績を含める

  • 2ゲスト戦 の成績は除外される

    • 1ゲームにゲストが2名以上いる場合、ゲストは同名のプレイヤーとして扱われ、成績が合算される

    • 正しく集計できないプレイヤーがゲームに存在するため、 2ゲスト戦 で記録された成績は集計対象外になる（ゲーム自体を無効にする）

  • ゲスト無効 の指定は効果がなくなる

  • 未登録メンバーはゲストに置換される
ゲストなし¶

集計結果からゲストの成績を除外する

  • ゲストプレイヤーの成績を集計対象外にする

    • 未登録メンバーはゲストに置換され、集計結果から除外される

    • 2ゲスト戦 の成績が計上されるようになる（ゲスト以外のプレイヤーの成績は集計される）

  • ゲスト無効 の指定は効果がなくなる
ゲスト無効¶

未登録メンバーをゲストに置き換えず、個別のメンバーとして集計する

  • 入力された名前のメンバーとして扱う

  • 敬称は削除される

  • ゲストが存在しなくなるため、 2ゲスト戦 が発生しない

    • すべてのゲームが集計対象になる

その他のオプション¶

キーワード

内容

備考

Player_XXX / Team_XXX に置換
