ルール設定ファイル¶

成績集計に使用する ルールセット を定義する。

ルールセット は以下で定義される。

  • メイン設定ファイル内「 mahjongセクション 」

    • 1セットのみ定義可能

    • セクションの省略可能

  • メイン設定ファイル内「 settingセクション 」の rule_config で指定される設定ファイル

    • 複数セットの定義が可能

    • 省略可能

rule_config で指定される設定ファイルでは ルールセット を区別できるユニークなセクションを設け、そのセクション内にパラメータを定義する。

Tip

ルールセット 定義がすべて省略された場合はプリセット（ default_rule.ini ）が使用される。

設定内容

  • ルールセット定義
    • ルール識別子省略時の挙動
    • メモ記録ワード省略時の挙動
  • レギュレーション設定
    • 個人清算レギュレーション
    • チーム清算レギュレーション
    • レギュレーション設定例
  • ルールセット個別レギュレーション設定
    • 読み込み優先順位
