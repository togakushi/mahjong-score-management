チーム一覧表示
==============

登録されているチーム名とそのチームに所属する `メンバー` を表示する。

:コマンドタイプ: `function-others`
:必須オプション: なし
:ターゲット指定: 無効
:個別オプション: なし


コマンド構文
------------

:チャンネル内呼び出し: <チーム一覧表示コマンド>

   .. note:: ``チーム一覧表示コマンド`` は以下で定義される

      - `team-section` の :team_section:`commandword`

:スラッシュコマンド: /commandname team_list

   .. seealso:: `slash_commands-team_list` コマンド

   .. include:: /material/commandname.inc


項目説明
--------
:チーム名: 登録されているチーム名
:所属メンバー: 所属している `メンバー` のリスト


制約事項
--------

- `ゲストメンバー` はチームに所属することはできない
- 複数チームに所属することはできない
