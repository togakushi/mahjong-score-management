用語集
======

.. glossary::

   メンバー : 用語(プレイヤー)
      | 管理対象になる個人
      | メンバーリストに登録されているかで `レギュラー` / `ゲスト` に分かれる

   プレイヤー : 用語(プレイヤー)
      ゲームに参加した `メンバー`、その人を識別する名前

   ゲスト : 用語(プレイヤー)
   ゲストメンバー : 用語(プレイヤー)
   ゲストプレイヤー : 用語(プレイヤー)
      メンバー登録されていない `プレイヤー` 、 `メンバー`

   レギュラー : 用語(プレイヤー)
   レギュラーメンバー : 用語(プレイヤー)
   レギュラープレイヤー : 用語(プレイヤー)
      メンバー登録されている、成績管理対象の `プレイヤー` 、 `メンバー`

   素点 : 用語(ルール)
      プレイヤーが所持している点棒の合計値

   ポイント : 用語(ルール)
      ゲーム終了時に素点から順位を決め、ウマ・オカを加えた値

   2ゲスト戦 : 用語
      ゲストが2名以上参加しているゲーム

   ゲーム : 用語
      半荘など精算の区切りの単位

   集計 : 用語(処理)
      | 蓄積したデータから特定の `ターゲット` の成績を集計/計算する処理を指す
      | 対象の `ターゲット` のデータのみを用いて計算される

   分析 : 用語(処理)
      | 蓄積したデータから多角的に成績を集計/計算する処理を指す
      | 全体平均との比較や、 `メンバー` 同士の成績比較、傾向を分析する

   突合 : 用語(処理)
   突合処理 : 用語(処理)
      Slack / Discord 上の入力情報を読み込み直し、DBの登録状況を最新化する

   ルールセット : 用語(ルール)
      | 集計に影響のあるルール(配給原点、返し点、順位点、など)をパラメータ化してまとめたもの
      | 集計の基本単位となる

   ルール識別子 : 用語(ルール)
      `ルールセット` に付けた名称

   コマンド : 用語(コマンド)
      ツールに対して動作の指示を与えるキーワード全般を指す用語

   ターゲット : 用語(コマンド)
      コマンドの集計対象として指定する `プレイヤー` および チーム を指す用語

   オプション : 用語(コマンド)
      コマンドの動作を変更するためにコマンドに渡すキーワード

   パラメータ : 用語(コマンド)
      | コマンドに渡す `ターゲット` 、 `オプション` をすべて含めた総称
      | `オプション` は特定のひとつを指し示すのに用いられるが、 `パラメータ` は全体（複数をまとめて）指し示すときに用いられる
