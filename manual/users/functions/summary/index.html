集計コマンド¶

指定期間内の対象プレイヤー/チームのポイントをそれぞれ集計する。

コマンド構文¶

チャンネル内呼び出し:

<集計コマンド> [ターゲット] [オプション]

Note

集計コマンド は以下で定義される

  • summaryセクション の commandword

スラッシュコマンド:

/commandname summary [ターゲット] [オプション]

Note

/commandname は以下で定義される

  • slackセクション の slash_command

  • discordセクション の slash_command
