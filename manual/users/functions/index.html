コマンド処理ロジック¶

入力された文字列は以下の順序で評価され、出力される内容が決定される。

  1. コマンド 部分と オプション 部分の分割

    スペース区切りで分割され、最初のブロックがコマンド、残りのブロックはすべてオプションとして扱われる

  2. ショートカットの適応

    • ショートカットが設定されていれば、コマンド部分とショートカットを置換する

      See also

      shortcutセクション

  3. コマンド種別の判定

    • 集計コマンド

    • 分析コマンド

    • その他のコマンド

  4. ターゲットの判定

    ターゲットの指定方法とコマンド種別の組み合わせで出力内容が決定される

    • 未指定（任意）

    • 単独指定

    • 複数指定

  5. オプションの評価

    See also
