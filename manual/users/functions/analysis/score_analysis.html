素点分析¶

各着順獲得時の素点状況を分析する。

コマンドタイプ:

分析コマンド

必須オプション:

素点

ターゲット指定:

任意

個別オプション:

なし

オプション¶

分類

項目

内容

共通オプション
プレイヤー名
チーム名
ターゲット の指定。
指定プレイヤー/チームだけで表を生成する。

集計範囲指定

日付指定オプション を参照。

その他のオプション

その他の共通オプション を参照。

項目説明¶

平均素点

ゲーム終了時点の素点平均

x位偏差
x位の全体平均素点と集計対象の平均素点の差分
x位偏差 = 集計対象のx位平均素点 - 全体のx位平均素点
