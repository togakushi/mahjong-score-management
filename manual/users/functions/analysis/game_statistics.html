ゲーム統計情報¶

ゲーム全体の傾向を月単位でまとめる。

コマンドタイプ:

分析コマンド

必須オプション:

統計

ターゲット指定:

任意

個別オプション:

なし

オプション¶

分類

項目

内容

共通オプション
プレイヤー名
チーム名
ターゲット の指定。
無視される。

Note

単独指定時は 成績詳細 に切り替わる。

集計範囲指定

日付指定オプション を参照。

グラフ集約オプション
年次 のみ有効。その他はすべて 月次 となる。
集約オプション を参照。

その他のオプション

その他の共通オプション を参照。

項目説明¶

集計月 / 集計年

集計単位となる月、年

対戦数

集計単位期間の対戦数

供託

ゲーム終了時点の素点合計と配給原点との差分

  • 精算時に回収されない供託の点棒

  • 入力した素点情報に誤りがある

飛んだ人数(延べ)

精算時に素点がマイナスとなっている プレイヤー の人数

トビ終了率

飛んだ人数 / 対戦数 * 100 の割合

Tip

1ゲームで複数人がマイナスになりえるので 100% を超える可能性がある

最大素点

集計単位期間のゲーム内の最大の素点

最小素点

集計単位期間のゲーム内の最小の素点
