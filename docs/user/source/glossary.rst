用語集
======

.. glossary::

   メンバー
      | 管理対象になる個人
      | メンバーリストに登録されているかでレギュラー/ゲストに分かれる

   プレイヤー
      ゲームに参加した個人、その人を識別する名前

   ゲスト
   ゲストメンバー
   ゲストプレイヤー
      メンバー登録されていないプレイヤー、メンバー

   レギュラー
   レギュラーメンバー
   レギュラープレイヤー
      メンバー登録されている、成績管理対象のプレイヤー、メンバー

   素点
      プレイヤーが所持している点棒の合計値

   ポイント
      ゲーム終了時に素点から順位を決め、ウマ・オカを加えた値

   通算ポイント
      集計範囲の各ゲームで獲得したポイントの合計値

   2ゲスト戦
      ゲストが2名以上参加しているゲーム

   ゲーム
      半荘など精算の区切りの単位

   突合
   突合処理
      Slack / Discord 上の入力情報を読み込み直し、DBの登録状況を最新化する [#]_ [#]_

   ルールセット
      | 集計に影響のあるルール(配給原点、返し点、順位点、など)をパラメータ化してまとめたもの
      | 集計の基本単位となる

   ルール識別子
      ルールセットに付けた名称

----

.. rubric:: 脚注

.. [#] 突合範囲は[サービス個別設定](config/integrations.md)の`search_after`で指定する。
.. [#] DBに記録済みのデータが Slack / Discord で見つからない場合は不要な記録としてDBから削除される。
