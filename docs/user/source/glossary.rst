用語集
======

.. glossary::

   メンバー : 用語(プレイヤー)
      | 管理対象になる個人
      | メンバーリストに登録されているかで `レギュラー` / `ゲスト` に分かれる

   プレイヤー : 用語(プレイヤー)
      ゲームに参加した個人、その人を識別する名前

   ゲスト : 用語(プレイヤー)
   ゲストメンバー : 用語(プレイヤー)
   ゲストプレイヤー : 用語(プレイヤー)
      メンバー登録されていないプレイヤー、メンバー

   レギュラー : 用語(プレイヤー)
   レギュラーメンバー : 用語(プレイヤー)
   レギュラープレイヤー : 用語(プレイヤー)
      メンバー登録されている、成績管理対象のプレイヤー、メンバー

   素点 : 用語(ルール)
      プレイヤーが所持している点棒の合計値

   ポイント : 用語(ルール)
      ゲーム終了時に素点から順位を決め、ウマ・オカを加えた値

   通算ポイント : 用語(ルール)
      集計範囲の各ゲームで獲得したポイントの合計値

   2ゲスト戦 : 用語
      ゲストが2名以上参加しているゲーム

   ゲーム : 用語
      半荘など精算の区切りの単位

   突合 : 用語(処理)
   突合処理 : 用語(処理)
      Slack / Discord 上の入力情報を読み込み直し、DBの登録状況を最新化する

   ルールセット : 用語(ルール)
      | 集計に影響のあるルール(配給原点、返し点、順位点、など)をパラメータ化してまとめたもの
      | 集計の基本単位となる

   ルール識別子 : 用語(ルール)
      ルールセットに付けた名称
