.. _grouping-options:

集約オプション
--------------

折れ線グラフの描写時にプロットするデータを集約するオプション。

| ゲーム単位でプロットされるデータを指定期間でまとめる。
| 合計値や平均値はまとめられる期間の最後のゲームを基準に計算される。

集約した結果、全プレイヤー/全チームのプロットするデータがでひとつになった場合は棒グラフに変化する。

.. list-table::
   :width: 100%
   :widths: 20 30 40
   :header-rows: 1

   * - キーワード
     - 内容
     - 備考
   * - .. common:: 日次, デイリー, daily
          :category: 集約オプション

     - 日単位で集計
     -
   * - .. common:: 週次, ウイークリー, weekly
          :category: 集約オプション

     - 週単位で集計
     - 月曜日始まり
   * - .. common:: 月次, マンスリー, monthly
          :category: 集約オプション

     - 月単位で集計
     -
   * - .. common:: 年次, イヤーリー, yearly
          :category: 集約オプション

     - 年単位で集計
     -
   * - .. common:: 全体
          :category: 集約オプション

     - 指定期間全体で集計
     - 強制的に横棒グラフになる
..
