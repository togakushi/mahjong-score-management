オプションに指定できる共通キーワード
====================================

.. tip::
   複数のオプションが同時に指定されている場合は出現順序で処理され、結果を上書きしていく。


検索範囲指定オプション
----------------------

集計の範囲や対戦数を調整するオプション。

.. _date-specification:

日付指定オプション
++++++++++++++++++

指定されたキーワードを基にリストに追加する。

- キーワードは複数指定可能
- 実行時の時間を基準に算出
- リスト内の最小値と最大値の期間を取る

.. list-table::
   :width: 100%
   :widths: 20 30 40
   :header-rows: 1

   * - キーワード
     - 追加される日付
     - 備考
   * - .. common:: 当日
          :category: 日付指定オプション

     - `time_adjust <time_adjust>` を考慮した時間の日付
     -
   * - .. common:: 今日
          :category: 日付指定オプション

     - 今日の日付
     -
   * - .. common:: 昨日
          :category: 日付指定オプション

     - 昨日の日付
     -
   * - .. common:: 先週
          :category: 日付指定オプション

     - | 先週の月曜日
       | 先週の日曜日
     - 実行日から7日前の週の月曜日～日曜日
   * - .. common:: 今週
          :category: 日付指定オプション

     - | 今週の月曜日
       | 今週の日曜日
     - | 実行日が含まれる週
       | 実行日が月曜日であればその週の日曜日まで
   * - .. common:: 今月
          :category: 日付指定オプション

     - | 今月月初の日付
       | 今月月末の日付
     -
   * - .. common:: 先月
          :category: 日付指定オプション

     - | 先月月初の日付
       | 先月月末の日付
     -
   * - .. common:: 先々月
          :category: 日付指定オプション

     - | 先々月月初の日付
       | 先々月月末の日付
     -
   * - .. common:: 今年
          :category: 日付指定オプション

     - | 今年の1月1日
       | 今年の12月31日
     -
   * - .. common:: 去年, 昨年
          :category: 日付指定オプション

     - | 前年の1月1日
       | 前年の12月31日
     -
   * - .. common:: 一昨年
          :category: 日付指定オプション

     - | 前々年の1月1日
       | 前々年の12月31日
     -
   * - .. common:: 最初
          :category: 日付指定オプション

     - 記録されている最初のレコードの前日
     - 集計対象のルール識別子で異なる日付が返る
   * - .. common:: 最後
          :category: 日付指定オプション

     - 翌日の日付
     -
   * - .. common:: 全部
          :category: 日付指定オプション

     - | 記録されている最初のレコードの前日
       | 翌日の日付
     - 最初から最後まで
   * - .. common:: YYYYMMDD
          :category: 日付指定オプション

     - 指定日 （連続した数字8桁）
     - MMとDDは常に2桁で指定する
   * - .. common:: YYYY-MM-DD, YYYY/MM/DD
          :category: 日付指定オプション

     - 指定日
     - MMとDDは常に2桁で指定する

ゲスト関連オプション
--------------------

`ゲストプレイヤー` の扱いを変更するオプション。

.. list-table::
   :width: 100%
   :widths: 20 30 40
   :header-rows: 1

   * - キーワード
     - 内容
     - 備考
   * - .. common:: ゲストあり
          :category: ゲスト関連オプション

     - 集計結果にゲストの成績を含める
     - - `2ゲスト戦` の成績は除外される

         - 1ゲームにゲストが2名以上いる場合、ゲストは同名のプレイヤーとして扱われ、成績が合算される
         - 正しく集計できないプレイヤーがゲームに存在するため、 `2ゲスト戦` で記録された成績は集計対象外になる（ゲーム自体を無効にする）

       - :common:`ゲスト無効` の指定は効果がなくなる
       - 未登録メンバーはゲストに置換される
   * - .. common:: ゲストなし
          :category: ゲスト関連オプション

     - 集計結果からゲストの成績を除外する
     - - ゲストプレイヤーの成績を集計対象外にする

         - 未登録メンバーはゲストに置換され、集計結果から除外される
         - `2ゲスト戦` の成績が計上されるようになる（ゲスト以外のプレイヤーの成績は集計される）

       - :common:`ゲスト無効` の指定は効果がなくなる
   * - .. common:: ゲスト無効
          :category: ゲスト関連オプション

     - 未登録メンバーをゲストに置き換えず、個別のメンバーとして集計する
     - - 入力された名前のメンバーとして扱う
       - 敬称は削除される
       - ゲストが存在しなくなるため、 `2ゲスト戦` が発生しない

         - すべてのゲームが集計対象になる

その他のオプション
------------------

.. list-table::
   :width: 100%
   :widths: 20 30 40
   :header-rows: 1

   * - キーワード
     - 内容
     - 備考
   * - .. common:: 匿名
          :category: その他のオプション

     - プレイヤー名/チーム名を伏せる
     - ``Player_XXX`` / ``Team_XXX`` に置換

   * - .. common:: 個人, 個人成績
          :category: その他のオプション

     - 個人集計を表示する
     - チーム集計オプションを上書きする
   * - .. common:: チーム, チーム成績, team
          :category: その他のオプション

     - チーム集計を表示する
     - 個人集計オプションを上書きする

   * - .. common:: 全員
          :category: その他のオプション

     - 登録済みプレイヤー/チームをすべて指定する
     - - 個人集計の場合はレギュラーメンバー全員
       - チーム集計の場合はすべてのチーム
