.. _graph-options:

グラフ集約オプション
====================

折れ線グラフの描写時にプロットするデータを集約するオプション。

| ゲーム単位でプロットされるデータを指定期間でまとめる。
| 合計値や平均値はまとめられる期間の最後のゲームを基準に計算される。

集約した結果、全プレイヤー/全チームのプロットするデータがでひとつになった場合は棒グラフに変化する。


オプション
----------

.. graph:: 日次, デイリー, daily
   :category: 集約オプション

   グラフを日単位で集計する。

.. graph:: 週次, ウイークリー, weekly
   :category: 集約オプション

   グラフを週単位で集計する。

.. graph:: 月次, マンスリー, monthly
   :category: 集約オプション

   グラフを月単位で集計する。

.. graph:: 年次, イヤーリー, yearly
   :category: 集約オプション

   グラフを年単位で集計する。

.. graph:: 全体
   :category: 集約オプション

   グラフを指定期間全体で集計する。

   - 強制的に横棒グラフになる
