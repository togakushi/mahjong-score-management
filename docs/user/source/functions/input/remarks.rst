メモ記録
========

| ゲーム結果に対してメモを残す機能。
| 「誰が」「何をした」の組み合わせで記録する。

役満和了やチョンボなど、ゲーム内での出来事を記録する目的で使用する。

``メモ記録キーワード`` は `rule-set` の ``remarks`` で定義する。

.. code-block:: text
   :caption: 入力フォーマット

   <メモ記録キーワード>
   <プレイヤー名> <内容>
   <プレイヤー名> <内容>

ひとつのメモ（メモ記録キーワード単位）で複数のメモが記録できる。

記録された ``内容`` は `table-words` テーブルに定義された ``type`` 別に集計される。


メモ
----

| ゲーム内で発生した出来事。
| `table-words` テーブルの ``type 0`` または ``type 1`` として登録している単語が ``メモ`` に該当する。

``type 0`` に分類される単語は「役満を和了した」ことを示す特別な単語として記録される。


卓外清算(個人清算)
------------------

| 個人成績に対する清算。
| `table-words` テーブルの ``type 2`` として登録している単語が ``個人清算`` に該当する。

祝儀や卓外ペナルティなどとして、素点とは別の要素として個人成績サマリ/個人成績詳細表示時にポイントを増減させる。


卓外清算(チーム清算)
--------------------

| チーム成績に対する清算。
| `table-words` テーブルの ``type 3`` として登録している単語が ``チーム清算`` に該当する。

チーム成績が表示される際、チームに所属しているメンバー全員の ``個人清算`` を合算し、さらに ``チーム清算`` を加えた値をポイントに反映させる。


入力ルール/制約事項等
---------------------

- `score-record` のスレッド内にポストされたものが記録対象になる
- 「記録キーワード」、「誰」、「何」は必ず空白/改行で区切る
- 1つのスレッド内に複数のメモが残せる
- 1つのメモの中に複数人(同一人物も可)のメモが残せる

  - 2人目以降は「誰」、「何」を繰り返す
  - 同一人物の同じ記録（チョンボを2回したなど）はポストを分けて入力する
  - 1つのポスト内のまったく同じ内容は集約されて1件になる

- スレッド元のスコア記録に「誰」が含まれていないと記録されない

  - ゲームに参加していないメンバーに対するメモは記録できない

出力される箇所
--------------

記録されているメモは、以下で確認できる。

- 全体成績サマリの最後にメモとして
- 個人成績サマリ / チーム成績サマリ

  - カウントされた回数が役満の回数として
  - 戦績の結果に内容が表示される
