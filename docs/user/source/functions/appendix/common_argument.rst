.. _common-argument:

引数に指定できる共通キーワード
==============================

.. tip::
   複数のオプションが同時に指定されている場合は出現順序で処理され、結果を上書きしていく。


検索範囲指定
------------

.. _date-specification:

日付指定
++++++++

.. program:: 共通(日付指定)

指定されたキーワードを基にリストに追加する。

- キーワードは複数指定可能
- 実行時の時間を基準に算出
- リスト内の最小値と最大値の期間を取る

.. list-table::
   :width: 100%
   :widths: 20 30 40
   :header-rows: 1

   * - キーワード
     - 追加される日付
     - 備考
   * - .. option:: 当日
     - ``time_adjust`` を考慮した時間の日付
     -
   * - .. option:: 今日
     - 今日の日付
     -
   * - .. option:: 昨日
     - 昨日の日付
     -
   * - .. option:: 先週
     - | 先週の月曜日
       | 先週の日曜日
     - 実行日から7日前の週の月曜日～日曜日
   * - .. option:: 今週
     - | 今週の月曜日
       | 今週の日曜日
     - | 実行日が含まれる週
       | 実行日が月曜日であればその週の日曜日まで
   * - .. option:: 今月
     - | 今月月初の日付
       | 今月月末の日付
     -
   * - .. option:: 先月
     - | 先月月初の日付
       | 先月月末の日付
     -
   * - .. option:: 先々月
     - | 先々月月初の日付
       | 先々月月末の日付
     -
   * - .. option:: 今年
     - | 今年の1月1日
       | 今年の12月31日
     -
   * - .. option:: 去年, 昨年
     - | 前年の1月1日
       | 前年の12月31日
     -
   * - .. option:: 一昨年
     - | 前々年の1月1日
       | 前々年の12月31日
     -
   * - .. option:: 最初
     - 記録されている最初のレコードの前日
     - 集計対象のルール識別子で異なる日付が返る
   * - .. option:: 最後
     - 翌日の日付
     -
   * - .. option:: 全部
     - | 記録されている最初のレコードの前日
       | 翌日の日付
     - 最初から最後まで
   * - YYYYMMDD
     - 指定日 （連続した数字8桁）
     - MMとDDは常に2桁で指定する
   * - | YYYY-MM-DD
       | YYYY/MM/DD
     - 指定日
     - MMとDDは常に2桁で指定する

.. _guest-option:

ゲスト関連
----------

.. program:: 共通(ゲスト関連)

.. list-table::
   :width: 100%
   :widths: 20 30 40
   :header-rows: 1

   * - キーワード
     - 内容
     - 備考
   * - .. option:: ゲストあり
     - 集計結果にゲストの成績を含める
     - - `2ゲスト戦` の成績は除外される

         - 1ゲームにゲストが2名以上いる場合、ゲストは同名のプレイヤーとして扱われ、成績が合算される
         - 正しく集計できないプレイヤーがゲームに存在するため、 `2ゲスト戦` で記録された成績は集計対象外になる（ゲーム自体を無効にする）

       - :option:`ゲスト無効` の指定は効果がなくなる
       - 未登録メンバーはゲストに置換される
   * - .. option:: ゲストなし
     - 集計結果からゲストの成績を除外する
     - - ゲストプレイヤーの成績を集計対象外にする

         - 未登録メンバーはゲストに置換され、集計結果から除外される
         - `2ゲスト戦` の成績が計上されるようになる（ゲスト以外のプレイヤーの成績は集計される）

       - :option:`ゲスト無効` の指定は効果がなくなる
   * - .. option:: ゲスト無効
     - 未登録メンバーをゲストに置き換えず、個別のメンバーとして集計する
     - - 入力された名前のメンバーとして扱う
       - 敬称は削除される
       - ゲストが存在しなくなるため、 `2ゲスト戦` が発生しない

         - すべてのゲームが集計対象になる
