オプション組み合わせ早見表
===========================

オプションの組み合わせで出力される内容

凡例
   :空欄: 未指定
   :|:/:|: 表示内容を決める必須オプション
   :|:o:|: 表示内容に追加情報を増やすオプション
   :|:-:|: 指定しても無視されるオプション

プレイヤー名/チーム名指定の条件
   :任意: 未指定、または、複数指定(単独の条件を満たしていないこと)
   :単独: 1名(1チーム)だけを単独指定
   :複数: 2名(2チーム)以上を複数指定

共通オプション
   :集計範囲指定: `date-specification` を参照
   :その他のオプション: `common-options` を参照
