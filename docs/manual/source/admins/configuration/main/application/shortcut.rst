shortcutセクション
==================

コマンドの評価前にコマンドを置き換えるキーワードを定義する。

動作概要
--------

入力される文字列をスペースで区切ったときの先頭のブロックがコマンドとして認識され、そのコマンドが `shortcut-section` のキーと一致している場合に値と置き換える。

.. important::

   | コマンドの内容が評価されるのは置換後となる。
   | 設定次第では無効なコマンドに置き換えられ、正しく動作しなくなるので注意すること。


（参考）設定例
--------------

.. code-block:: ini
   :caption: ショートカットの設定例

   [shortcut]
   成績グラフ = 成績集計 グラフ
   成績ランキング = 成績分析 今年 ゲストなし

置き換えの例
   :入力文字列: **成績グラフ** 今月 ゲストなし
   :変換後: **成績集計 グラフ** 今月 ゲストなし

   ..

   :入力文字列: **成績ランキング** 全部 ゲスト無効
   :変換後: **成績分析 今年 ゲストなし** 全部 ゲスト無効

      .. hint::

         集計範囲は ``今年`` と ``全部`` が合算される。

         - 複数の範囲キーワードを指定した場合の動作については `date-specification` を参照
         - ゲストを取り扱うオプションが複数指定されている場合の動作については `guest-option` を参照
