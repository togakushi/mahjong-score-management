score_simulator.py
==================

.. program:: dbtools.py

概要
----

1半荘のゲームスコアをシミュレートする。

- モジュールとして実行した場合はシミュレート結果をリストで返す
- コマンドラインツールとして実行した場合はシミュレート結果を標準出力に返す

.. code-block:: shell
   :caption: 実行例

   $ uv run libs/functions/tools/score_simulator.py
   最終素点: [27800, -5200, 34800, 42600] 素点合計 100000


コマンドライン引数
------------------

なし
