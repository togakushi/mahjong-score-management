直接対戦結果
============

指定した対戦相手と同卓したゲームの内容について集計する。

:コマンドタイプ: `function-summary`
:必須オプション: :common:`対戦` or :common:`対戦結果`
:ターゲット指定: 複数
:個別オプション: なし


オプション
----------

.. flat-table::
   :header-rows: 1
   :width: 100%
   :widths: 10 20 70

   * - 分類
     - 項目
     - 内容
   * - :rspan:`2` 共通オプション
     - | プレイヤー名
       | チーム名
     - | `ターゲット` の指定。2名(2チーム)以上を指定する。
       | 最初に指定されたプレイヤー/チームを対象に、それ以降のプレイヤー/チームとの対戦結果をそれぞれ集計する。

       .. hint::

          対戦相手として :common:`全員` を指定するとレギュラーメンバー全員/登録チームすべてとの対戦結果が集計される。

   * - 集計範囲指定
     - `date-specification` を参照。
   * - その他のオプション
     - `common-options` を参照。


項目説明
--------

対戦数
   集計期間の対戦数

   :勝: 対戦相手より着順が上のゲーム数
   :敗: 対戦相手より着順が下のゲーム数
   :分: 対戦相手と着順が同じゲーム数

平均素点差
   対戦相手の平均素点との差分

獲得ポイント合計(自分/相手)
   集計対象ゲームで獲得したポイントの合計値。

順位分布(自分/相手)
   | 獲得した順位の回数と平均順位。
   | 以下の形式で表現される。

   ``1位回数 + 2位回数 + 3位回数 + 4位回数 = トータルゲーム数（平均順位）``
