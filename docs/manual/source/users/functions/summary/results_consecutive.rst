連続戦集計
==========

集計範囲内の連続した結果を指定された対戦数に区切って集計する。

:コマンドタイプ: `function-summary`
:必須オプション: :summary:`連続`
:ターゲット指定: 任意
:個別オプション: `あり <option-summary>`

集計例（集計範囲に10戦分の対戦結果があり、回数が5と指定された場合）
   以下の6通りを算出し、合計値の大小で順位を付ける。

   - 1戦目～5戦目の合計
   - 2戦目～6戦目の合計
   - (中略)
   - 6戦目～10回目の合計

   集計範囲に含まれるすべてのプレイヤー/チームに対して同様の集計を行う。

   .. tip:: 総対戦数が多い方が算出される結果が多くなるため有利になる。


オプション
----------

.. flat-table::
   :header-rows: 1
   :width: 100%
   :widths: 10 20 70

   * - 分類
     - 項目
     - 内容
   * - 必須オプション
     - :summary:`連続`
     - 集計する対戦数（区切り数）の指定。``1`` 以上の値を指定する。

       :指定例: 連続5
   * - :rspan:`2` 共通オプション
     - | プレイヤー名
       | チーム名
     - | `ターゲット` の指定。
       | 指定プレイヤー/チームのみに絞って集計する。
   * - 集計範囲指定
     - `date-specification` を参照。
   * - その他のオプション
     - `common-options` を参照。
   * - :rspan:`3` 個別オプション
     - :summary:`ベスト`
     - 集計結果を上位から指定数までを表示。

       :指定例: ベスト10
   * - :summary:`ワースト`
     - 集計結果を下位から指定数までを表示。

       :指定例: ワースト10
   * - :summary:`戦績`
     - ポイント合計の内訳と総対戦数の追加表示。
   * - :summary:`詳細`
     - 集計対象の初戦と最終戦の日時と総対戦数の追加表示。

.. note::

   :summary:`ベスト` / :summary:`ワースト` の指定が省略された場合、デフォルト値として以下の設定が使用される。

   - :sub_commands_section:`ranked` までの順位
   - :sub_commands_section:`reverse` で指定されている順序（昇順/降順）
