成績詳細
========

個人成績/チーム成績の詳細を表示する。

:コマンドタイプ: `function-summary`
:必須オプション: なし
:ターゲット指定: 単独
:個別オプション: `あり <option-summary>`


オプション
----------

.. flat-table::
   :header-rows: 1
   :width: 100%
   :widths: 10 20 70

   * - 分類
     - 項目
     - 内容
   * - :rspan:`2` 共通オプション
     - | プレイヤー名
       | チーム名
     - | `ターゲット` の指定（単独）。
       | 指定プレイヤー/チームの成績を集計する。
   * - 集計範囲指定
     - `date-specification` を参照。
   * - その他のオプション
     - `common-options` を参照。
   * - :rspan:`3` 個別オプション
     - :summary:`統計`
     - 座席データ、ベストレコード、ワーストレコード、平均収支を追加表示する。
   * - :summary:`戦績`
     - 戦績データ（ゲーム単位の素点、順位、獲得ポイント）を表示する。
   * - :summary:`詳細`
     - 戦績データを4人分表示する。

       .. note:: :summary:`戦績` と同時指定した場合のみ有効

   * - | :summary:`対戦`
       | :summary:`対戦結果`
     - 同卓者との勝敗を表示する。

   * - その他
     - :summary:`グラフ`
     - `deliverables-results_graph` に切り替える。


項目説明
--------

.. describe:: 対戦数

   集計範囲の対戦数

   :勝: ポイントがプラスのゲーム数
   :敗: ポイントがマイナスのゲーム数
   :分: ポイントが±0のゲーム数

.. describe:: 平均収支

   ゲーム終了時の平均素点から配給原点を差し引いた点数

.. glossary::

   ベストレコード : 用語(成績項目)
      :連続トップ: 集計範囲で連続で1位を獲得した最大数
      :連続連対: 集計範囲で連続で1位または2位を獲得した最大数
      :連続ラス回避: 集計範囲で連続で1位～3位を獲得した最大数
      :最大素点: 集計範囲で獲得した素点の最大値
      :最大獲得ポイント: 集計範囲で獲得したポイントの最大値（順位点加算後のポイント）

   ワーストレコード : 用語(成績項目)
      :連続ラス: 集計範囲で連続で4位を獲得した最大数
      :連続逆連対: 集計範囲で連続で3位または4位を獲得した最大数
      :連続トップなし: 集計範囲で連続で2位～4位を獲得した最大数
      :最小素点: 集計範囲で獲得した素点の最小値
      :最小獲得ポイント: 集計範囲で獲得したポイントの最小値（順位点加算後のポイント）
