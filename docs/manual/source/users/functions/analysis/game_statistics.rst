ゲーム統計情報
==============

ゲーム全体の傾向を月単位でまとめる。

:コマンドタイプ: `function-analysis`
:必須オプション: :analysis:`統計`
:ターゲット指定: 任意
:個別オプション: なし

オプション
----------

.. flat-table::
   :header-rows: 1
   :width: 100%
   :widths: 10 20 70

   * - 分類
     - 項目
     - 内容
   * - :rspan:`3` 共通オプション
     - | プレイヤー名
       | チーム名
     - | `ターゲット` の指定。
       | 無視される。

       .. note:: 単独指定時は `deliverables-results_details` に切り替わる。

   * - 集計範囲指定
     - `date-specification` を参照。
   * - 集約オプション
     - | `年次` / `全体` のみ有効。無効な集約オプションはすべて `月次` として扱われる。
       | `grouping-options` を参照。
   * - その他のオプション
     - `common-options` を参照。

項目説明
--------

集計月 / 集計年 / 集計
   | 集計単位となる月、年
   | 集約オプションに `全体` が指定されている場合は「集計」と表示される

対戦数
   集計単位期間の対戦数

供託
   ゲーム終了時点の素点合計と配給原点との差分

   - 精算時に回収されない供託の点棒
   - 入力した素点情報に誤りがある

飛んだ人数(延べ)
   精算時に素点がマイナスとなっている `プレイヤー` の人数

トビ終了率
   ``飛んだ人数 / 対戦数 * 100`` の割合

   .. tip:: 1ゲームで複数人がマイナスになりえるので 100% を超える可能性がある

最大素点
   集計単位期間のゲーム内の最大の素点

最小素点
   集計単位期間のゲーム内の最小の素点
