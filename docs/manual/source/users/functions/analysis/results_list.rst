成績詳細一覧表
==============

`deliverables-results_details` の内容を比較できるように並べて表示する。

:コマンドタイプ: `function-analysis`
:必須オプション: :analysis:`比較`
:ターゲット指定: 任意
:個別オプション: `あり <option-analysis>`


オプション
----------

.. flat-table::
   :header-rows: 1
   :width: 100%
   :widths: 10 20 70

   * - 分類
     - 項目
     - 内容
   * - :rspan:`2` 共通オプション
     - | プレイヤー名
       | チーム名
     - | `ターゲット` の指定。
       | 指定プレイヤー/チームの成績を表示する。
       | 未指定時は全員分が表示される。
   * - 集計範囲指定
     - `date-specification` を参照。
   * - その他のオプション
     - `common-options` を参照。
   * - 個別オプション
     - :analysis:`詳細`
     - 収支情報、 `ベストレコード` 、 `ワーストレコード` の追加表示

項目説明
--------

戦績(勝-敗-分)
   対戦の内訳

   :勝: ポイントがプラスのゲーム数
   :敗: ポイントがマイナスのゲーム数
   :分: ポイントが±0のゲーム数

xxxx率(回)
   | xxxxの発生回数を対戦数で割った割合
   | 括弧内はxxxxの発生回数

平均収支
   ゲーム終了時点の素点平均から配給原点を引いた点数

連対収支
   1位、2位獲得時の最終素点平均から配給原点を引いた点数

逆連対収支
   3位、4位獲得時の最終素点平均から配給原点を引いた点数

x位収支
   x位獲得時の最終素点平均から配給原点を引いた点数

連続トップ / 連続連対 / 連続ラス回避 / 最大素点 / 最大獲得ポイント
   `ベストレコード` を参照

連続トップなし / 連続逆連対 / 連続ラス / 最小素点 / 最小獲得ポイント
   `ワーストレコード` を参照
