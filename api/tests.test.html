tests.test module¶

test.py

tests.test.test_pattern(flag, test_case, sec, pattern, argument)¶

テストケース実行

Parameters:

  • flag (dict[str, Any]) – フラグ格納辞書

  • test_case (str) – テストケース

  • sec (str) – 定義セクション

  • pattern (str) – 実行パターン

  • argument (str) – コマンドライン引数

Return type:

None

tests.test.main()¶

テストケース定義に従ってパターン実行を行う。

設定ファイルを読み込み、対象パターンごとに前処理を適用したうえで test_pattern を呼び出す。

None
