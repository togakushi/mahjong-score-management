tests.name_check.test_name module¶

メンバー名の許可/拒否パターン判定を検証するテスト。

tests.name_check.test_name.parser_instance()¶

名前検証テストの共通初期化を行う。

設定読込とメンバー一覧準備を実行し、検証関数の前提を整える。

Parameters:

None.

Returns:

テスト前処理を実行し制御を返すジェネレータ。

Return type:

Generator[None, Any, None]

tests.name_check.test_name.test_name_permit(input_args, expected_flags, parser_instance)¶

登録許可パターンの名前判定結果を検証する。

check_namepattern が True を返すべきケースで期待値と一致するか確認する。

Parameters:

  • input_args (str) – 検証対象の名前文字列。

  • expected_flags (bool) – 期待する判定結果。

  • parser_instance (Any) – 初期化済み環境を準備するフィクスチャ。

Return type:

None
